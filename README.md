# 📦 Amazon Data Analyst Project | Power BI

## 📌 Project Overview
This project analyzes Amazon sales data to uncover **product performance trends**, **category-wise sales behavior**, and **order fulfillment patterns**.  
The primary focus is to identify underperforming product categories and understand how **discounts, ratings, and fulfillment methods** impact sales and operational efficiency.

## 🔄 Data Processing Workflow
1. Collected Amazon sales and product data  
2. Cleaned missing values, duplicates, and inconsistent records  
3. Standardized product categories, courier status, and fulfillment types  
4. Created calculated measures for total sales, category counts, and shipment status  
5. Built interactive Power BI dashboards with slicers and filters  

---

## 📌 Conclusion
Through detailed analysis of Amazon sales data using Power BI, I identified key trends in product performance, fulfillment efficiency, and regional demand. The analysis revealed that a small number of product categories and sizes contribute significantly to total sales, while certain categories consistently underperform despite discounting.

The dashboard also highlighted the importance of efficient fulfillment and logistics, with most orders successfully shipped and Amazon fulfillment handling a major share of deliveries.
